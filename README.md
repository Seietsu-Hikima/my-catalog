# ハンドメイド作品カタログ

ビルド不要の、静的な作品カタログです。

## 起動する

追加のインストールは不要です(Windows 専用)。

1. `start.cmd` をダブルクリックします。黒いウィンドウが開きます。
2. ブラウザで <http://localhost:3000/> を開きます。

止めるときは、黒いウィンドウを閉じます。起動中はウィンドウを開いたままにしてください。

ターミナルから起動する場合は、このフォルダで次を実行します。ポートは `-Port` で変更できます。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\serve.ps1 -Port 3001
```

「Could not start on port 3000」と出る場合は、すでに起動しているか、他のアプリがポート 3000 を使っています。起動中のウィンドウを閉じるか、別のポートを指定してください。

このアドレスを開けるのは、起動しているパソコンからだけです。`index.html` をダブルクリックして開くこともできますが、カートの中身は `localhost:3000` で開いたときとは別々に保存されます。

## 作品を追加・変更する

作品は Notion の「作品」データベースで管理します。Notion を変更しただけではカタログは変わらず、次の手順で反映します。接続の準備は `ADMIN.md` を見てください。

1. 写真を `images/` フォルダに入れます。
2. Notion か管理画面で作品を追加・変更します。
3. `sync-works.cmd` をダブルクリックします。Notion の内容で `works.js` の `WORKS` が書き換わります。
4. ブラウザを再読み込みして確認します。公開中のサイトを更新するには、アップロードし直します。

`WORKS` は同期のたびに上書きされるので、`works.js` で直接編集しないでください。

| Notion の列 | カタログでの表示 |
| ------------------- | ------------------------------------------------ |
| 作品名              | 作品名。空の行は出ません |
| 価格                | 税込の金額。数字のみ。空ならカートに入れられません |
| 写真URL             | `images/photo1.jpg` の形か、画像のURL。1枚だけです |
| 説明                | 説明文 |
| 素材・サイズ        | テキスト列を追加すると表示されます。なくても動きます |
| 状態                | 下の表のとおり |
| 削除済み            | チェックがあると出ません |

| Notion の状態     | カタログでの表示 |
| ----------------- | ------------------ |
| 公開中 / 販売中   | 販売中             |
| 受注制作          | 受注制作           |
| 売り切れ          | 売り切れ           |
| それ以外・空      | 出ません(非公開) |

変更前の `works.js` は `works.backup.js` に保存されます。Notion を読めないときや、公開できる作品が1件もないときは、`works.js` は変わりません。書き込まずに結果だけ見るには、次を実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\sync-works.ps1 -DryRun
```

工房の名前と紹介文、「会社情報」ページに出る責任者(`owner`)・住所(`address`)・電話番号(`phone`)は、`works.js` の先頭にある `SHOP` で変更できます。責任者・住所・電話番号は、空 `""` にするとその行が表示されません。

### うまく表示されないとき

- 「作品データを読み込めませんでした」と出る場合は、`works.js` の書き間違いです。`SHOP` の `,` や `"` の閉じ忘れを確認してください。
- 作品が出ない場合は、`sync-works.cmd` の表示を確認してください。`Not published` と出た作品は、状態が上の表にありません。
- 写真が「画像なし」になる場合は、ファイル名と「写真URL」の指定が一致しているか確認してください。公開先では大文字と小文字も区別されるため、`Photo.JPG` と `photo.jpg` は別のファイルとして扱われます。
- 写真のファイル名は、半角英数字にしておくと安全です。一覧では正方形に切り抜いて表示されます。

## カートについて

カートの中身は、見ている人のブラウザの中だけに保存されます。店側に注文は届かず、決済もできません。そのためカート画面には「ご注文方法は現在準備中です」と表示しています。注文を受け付けるには、注文方法を決めたうえで、別途つなぎ込みが必要です。

## 公開する

公開すると、URLを知っている人は誰でも見られます。仮データ(`works.js` と `images/sample-*.svg`)を本物に差し替えてから公開してください。公開前に `sync-works.cmd` を実行して、Notion の内容を反映しておきます。特に、責任者・住所・電話番号の仮の値は実在の場所や番号につながる可能性があるため、必ず差し替えるか空にしてください。

公開先で使うのは `index.html`、`app.js`、`works.js`、`styles.css`、`images` だけです。`start.cmd`、`serve.ps1`、管理画面や同期のファイル(`ADMIN.md` を参照)、`works.backup.js`、`.claude` は外してアップロードすると、余計なファイルが公開されません。

### Netlify Drop(手軽な方法)

1. <https://app.netlify.com/drop> を開きます。
2. `my-catalog` フォルダをページにドラッグ&ドロップします。
3. 表示されたURLで確認します。残しておくには、案内に従って無料アカウントを作成します。

更新するときは、Netlify の管理画面からフォルダをアップロードし直します。

### GitHub Pages

1. GitHub に公開リポジトリを作成し、このフォルダの中身をアップロードします。
2. リポジトリの Settings → Pages を開きます。
3. Source で「Deploy from a branch」、ブランチで `main` と `/ (root)` を選んで保存します。
4. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

リポジトリの中身も公開されるため、見られて困るファイルは入れないでください。
