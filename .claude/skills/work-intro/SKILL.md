# 作品紹介文（work-intro）

作品や商品の紹介文を、いつも同じ形・同じ長さ・同じ語り口で書くための手順です。
形をそろえると、商品ページやカタログに並べたときに読みやすく、見る人が必要な情報をすぐ見つけられます。

## 出力の型

次の3つの見出しを、この順番・この名前のまま使います。

```
## 作品名と素材
（作品名と主な素材を1文で）

## 見どころ
（いちばんの魅力を1〜2文で）

## お手入れ
（扱い方やお手入れ方法を1文で）
```

## 書き方のルール

- **長さ**：見出しを除いた本文の合計を、110〜130字にします（1見出しあたり約40字）。商品カードのような小さな枠にも収まり、ひと目で読み切れる長さだからです。書き終えたら文字数を数え、外れていれば言葉を足したり削ったりして調整します。文字数には句読点やかぎかっこも含めます。
- **語り口**：です・ます調で、やわらかく親しみやすく書きます。「最高級」「絶対に」のような大げさな宣伝文句は使いません。信頼できる手作りの店らしい、落ち着いた温かさを大切にします。
- **見どころ**：素材の説明の繰り返しではなく、使う人がうれしくなる点（形、手ざわり、使い心地、使う場面など）を1つに絞って書きます。
- 紹介文のあとに、`（本文 ◯◯字）` と文字数を1行だけ添えます。

## 情報が足りないとき

素材やお手入れ方法が分からないときは、**それらしい内容を作らないでください**。素材やお手入れを間違えると、買った人が作品を傷めたり、アレルギーなどで困ったりするためです。

- 分からない点が素材やお手入れなら、書く前にユーザーに確認します（例：「表地と裏地の素材と、洗濯できるかを教えてください」）。
- ユーザーが「とりあえず書いて」と言った場合は、その部分を `【素材を記入】` のように空欄にして書き、あとで埋める必要があることを伝えます。

## NEKOMO の商品の場合

このプロジェクトの `script.js` にある `products` 配列に、商品名（`name`）と説明（`desc`）が入っています。NEKOMO の商品の紹介文を頼まれたら、まずここを読んで素材や特徴を確認します。ここに書かれていないこと（たとえば具体的なお手入れ方法）を付け足すときは、素材から無理なく言える一般的な内容にとどめ、そう書いたことをユーザーに伝えます。

## 見本

**見本1（NEKOMO の商品）**

```
## 作品名と素材
「ねこ耳スマホケース」は、衝撃に強いTPU素材でできたスマホケースです。

## 見どころ
ぴょこんと飛び出た猫耳がポイント。手に取るたびに、ほっこりした気持ちになれます。

## お手入れ
汚れが気になるときは、水でぬらしてかたくしぼったやわらかい布で、やさしく拭いてください。
```
（本文 120字）

**見本2（手作り作品）**

```
## 作品名と素材
くるみの木から一本ずつ削り出した、手作りの木のスプーンです。

## 見どころ
木目がひとつずつ違い、毎日使うほどに色が深まって、手にやさしくなじんでいきます。

## お手入れ
使ったあとは水で洗ってすぐに拭き、よく乾いたらときどき食用のオイルを薄く塗ってください。
```
（本文 114字）
