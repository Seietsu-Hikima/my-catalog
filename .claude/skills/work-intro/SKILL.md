# 作品紹介文を書く

対象: $ARGUMENTS

対象の指定がないとき、または「○○」のような置き換え前の文字のままのときは、どの作品について書くかを尋ねる。

## 手順

1. `works.js` を読み、`WORKS` から対象の作品を見つける。`WORKS` は Notion から同期した内容なので、見つからなければ、作品の一覧を示して、Notion に登録して `sync-works.cmd` を実行するか、作品名を選び直すよう案内する。
2. `name`、`material`、`size`、`status`、今の `description` を確認する。`images` の写真を読めるなら、見た目の確認に使う。
3. 下の「形式」と「書き方」に沿って紹介文の案を書き、チャットで示す。
4. 反映は、利用者に Notion か管理画面の「説明」欄へ貼り付けてもらい、`sync-works.cmd` を実行するよう案内する。`works.js` は同期で上書きされるので、直接書き換えない。

## 形式

1行目を見出しの「おすすめ」にして、2行目から本文を書く。

```
おすすめ
本文
```

Notion の「説明」欄には、この2行をそのまま入れる。

## 書き方

- 本文は100字前後にする。見出しは字数に数えない。
- 「です・ます」調で、落ち着いた言葉を使う。感嘆符や誇張した表現は使わない。
- 手ざわり、色合い、使う場面など、読んだ人が手に取る様子を思い描ける内容にする。

## 書かないこと

- 作品データや利用者の話、写真から確かめられない素材、産地、製法、効能を書かない。必要なら利用者に尋ねる。
- 価格、サイズ、販売状況を書かない。これらは画面の別の場所に表示される。
